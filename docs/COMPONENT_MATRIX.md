# Component decision matrix

## Audit basis

The decisions below are based on source snapshots inspected on 2026-09-12:

- Hermes Agent `044a77b3b6af4ce16138d42762f812a20b9f7a89`
  (`0.21.2`, MIT).
- OpenJarvis `b1055c983b25b298c7e97723847d215df18de4a8`
  (dynamic version, Alpha classifier, Apache-2.0).
- PersonalJarvis `e56c43b0289643f738199abc02ce30d7bdbc8c0f`
  (`2.1.0`, Beta classifier, Apache-2.0).

Risk uses Low/Medium/High relative to Phase 2 integration and long-term upstream
change. `INSPIRE_ONLY` means no source reuse. `ADAPT_EXTERNAL` requires
file-level provenance and Apache NOTICE compliance if source is adapted.

## Result

Hermes remains the only runtime core. The only planned external source
adaptations are narrow Apple-local inference and macOS computer-use/permission
UX, each behind a JL-owned boundary. Everything else is reused from Hermes,
integrated through MCP, or retained as design inspiration.
